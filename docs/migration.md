# 旧システムからの移行・切り替え手順

これまで使っていた予約・顧客管理システムから Salon OS へ、**業務を止めずに・データを失わずに**切り替えるための手順です。
画面は **サロン管理 → データ移行**（店長・オーナーのみ）。

## 1. 取り込めるデータ

| 順番 | データ | 内容 | 取り込み先 |
|---|---|---|---|
| ① | 顧客 | 顧客番号・氏名・フリガナ・電話・メール・誕生日・性別・住所・職業・来店きっかけ・担当・タグ・メモ・DM可否・ポイント残高（有効期限）・来店回数・累計売上・初回/最終来店日・登録日 | 顧客台帳。対応する欄がない列も「旧システムから引き継いだ項目」として保存（失われない） |
| ② | 来店履歴・カルテ | 来店日時・担当・メニュー・金額・店舗・施術メモ（薬剤・レシピ）・伝票番号 | 顧客の「来店履歴」と「タイムライン」（移行データとして表示。Salon OS の売上分析には含めない） |
| ③ | 今後の予約 | 予約日時・終了時刻/所要時間・顧客・担当・メニュー・メモ・予約番号・予約経路 | 予約カレンダー（経路「移行」） |

列の見出しは自動で対応付けます（「会員番号」「お客様名」「携帯電話」「DM可否」「保有ポイント」など他システムの表記に対応）。違っていれば画面で変更できます。
ファイルは Shift_JIS・UTF-8 どちらでも可。和暦（S60.4.1）・Excel の日付シリアル値・「¥12,000」なども読み取ります。

## 2. 安全のための仕組み

- **取り込む前に確認**: 件数・取り込めない行と理由・既存顧客との一致・金額の合計・見つからないスタッフ/メニューを表示（この時点では何も登録しない）。
- **重複しない**: 顧客番号・伝票番号・予約番号（なければ行の内容）で判定し、同じファイルを何度取り込んでも二重登録しない。
- **家族を混同しない**: 電話番号やメールだけでは同一人物と判定しない（氏名またはフリガナも一致が必要）。
- **入力済みを上書きしない**: Salon OS に既にいる顧客は空欄だけ補う（設定でオフ可）。
- **お客様に連絡しない**: 移行した予約で確認メッセージは送らない。リマインドは「旧システムのリマインドを止めた場合のみ」オンにする。媒体（ホットペッパー/LiME）への枠止め依頼も作らない。
- **配信は同意がある人だけ**: DM可否の列がない顧客は配信しない扱い（設定で変更可）。
- **ポイントは1回だけ**: 顧客ごとに1回だけ残高を引き継ぐ（ポイント履歴に「旧システムからの移行」と記録）。
- **照合**: 取り込み後に「ファイルの行数・金額合計」と「Salon OS に入った件数・金額合計」を並べて表示。
- **取り消し**: 取り込みごとに取り消せる。取り込み後に予約・会計・カルテ・メモ・ポイント利用があった顧客や、変更・来店処理された予約は残す（業務で使ったデータは消さない）。
- **取り込めなかった行**: 元の列＋理由をCSVで書き出し、Excelで直して再取り込みできる。
- 実行・取り消しは監査ログに記録（`migration.import_start` / `migration.import_complete` / `migration.import_undo`）。

## 3. 切り替えまでの進め方（例: 切り替え日を「月曜」とする）

| 時期 | やること | 担当 |
|---|---|---|
| 2週間前 | 店舗設定（営業時間・定休日）、スタッフ（**旧システムと同じ表示名**）、メニュー（**予約で使っている名前と同じ**）、シフトを登録 | 店長 |
| 2週間前 | 旧システムから顧客・来店履歴をCSVで書き出し、**数十行の試しファイル**で取り込みを確認 → 問題なければ全件取り込み。照合結果の件数・金額を旧システムの集計と比べる | 店長 |
| 1週間前 | スタッフ全員で操作練習（予約登録・変更・来店・会計・カルテ）。ホットペッパー / LiME のメール連携を設定（[deploy.md](deploy.md) / ADR 0010） | 全員 |
| 前日の閉店後 | 旧システムで新しい予約を受けないよう設定し、**今後の予約**を書き出して取り込む。取り込めなかった予約（重なり・メニュー不一致）は一覧を見て手動で登録 | 店長 |
| 前日の閉店後 | 旧システム終了後に入った来店・会計があれば来店履歴を追加で取り込む（重複しない） | 店長 |
| 当日 | Salon OS で受付開始。予約カレンダーで当日分を旧システムの最後の画面と照合 | 受付 |
| 当日〜1週間 | 旧システムは**閲覧用に残す**（解約しない）。リマインドを Salon OS に切り替える場合は旧システム側を止めてから | 店長 |
| 1か月後 | 問題がなければ旧システムを解約（解約前に全データを書き出して保管） | オーナー |

## 4. よくある質問

- **スタッフ名が見つからないと出る**: スタッフ画面で旧システムと同じ表示名で登録してから取り込むと紐付きます。退職者は名前だけ記録されます。予約は空いているスタッフに割り当て、旧担当をメモに残します。
- **メニューが見つからないと出る（予約）**: 同じ名前のメニューを作るか、「メニューが見つからないとき」に既定メニューを選びます。旧システムの終了時刻が長い場合はその時間で枠を確保します。
- **同じ人が2人登録された**: 顧客画面の「重複候補」から統合できます。統合すると来店履歴・来店回数・累計売上・ポイントも合算されます（取り消し可）。
- **来店回数・累計売上はどうなる**: 旧システムの値に Salon OS での来店・会計が加算されて表示されます。
- **売上分析に旧システムの売上は入る？**: 入りません（会計データではないため）。過去の売上は旧システムの書き出しを保管してください。
