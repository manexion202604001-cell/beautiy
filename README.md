# MANEXION Salon OS

美容サロン向け業務OS。**顧客・予約・カルテ・会計・再来店を1つの顧客IDでつなぐ** Webアプリです。
公開情報から要件を定義し、UI・文章・ブランド・コードを独自に設計したクリーンルーム実装です。

## 主な機能

| 領域 | 画面 / 機能 |
|---|---|
| 認証・組織 | サロン新規登録（組織＋店舗＋オーナー）、スタッフ招待、6ロールのRBAC、店舗切替、監査ログ |
| 顧客CRM | 検索（氏名/カナ・電話/メールの完全一致）、ライフサイクル（新規/通常/周期超過/休眠）、タグ、LINE等の外部ID、重複検出と統合、CSV入出力 |
| 個人情報保護 | 電話・メール・住所をAES-256-GCMで暗号化、検索用ブラインドインデックス、権限外はマスク表示、OTPで30分間の一時ロック解除、閲覧・出力の監査記録 |
| 予約台帳 | スタッフ別の日表示／週表示、ドラッグで移動・リサイズ、ステータス管理、席数・スタッフ重複の防止（DBロック＋冪等キー）、席数超過の確認付き上書き、プライベート予定、相談予約、キャンセル待ち |
| ネット予約 | 会員登録不要、メニュー/クーポン→担当→日時→情報入力、10分間の仮押さえ、即時確定/リクエスト制、LINE連携リンク、変更・キャンセルURL |
| 電子カルテ | 1来店1カルテ、施術/薬剤/アシスタントメモ、テンプレート、前回コピー、音声入力、ビフォーアフター写真、スケッチ、お客様への共有ページ |
| カウンセリング | フォームビルダー、お客様の事前入力リンク、電子署名付き同意書 |
| POS・会計 | 予約から会計、施術/店販/その他、スタッフ別売上・指名、クーポン、ポイント利用/付与、分割払い、レシート、返金・取消、レジ開け/締め（過不足）、日次レポート |
| メッセージ | LINE/メールの受信箱、テンプレート、セグメント配信、自動配信（前日リマインド・来店周期・口コミ依頼・誕生日・休眠）、配信ログと再送、配信停止 |
| 口コミ・プロフィール | 口コミ管理と返信、店舗/スタイリストの公開プロフィール、OGP画像、来店後の口コミ投稿 |
| 分析・LTV | 売上（日次/月次・店舗合算/比較）、施術/店販、新規/再来、指名/フリー、決済方法、予約経路、スタッフKPI、LTV分布、休眠候補、メニューランキング、CSV |
| 店販EC | 商品管理、オンラインストア、カート、注文・発送管理、定期便、スタイリストのおすすめリンク |
| 外部連携 | LINE Messaging API、Stripe/Square（Webhook冪等処理）、外部予約サイトの同期レイヤー（署名検証・冪等・競合検出・リトライ/デッドレター・手動照合）、Google/Instagramアダプタ |
| 多店舗 | 店舗ごとの営業時間・席数・メニュー、スタッフの複数店舗所属、横断顧客タイムライン、合算/店舗別売上 |

## 構成

```
apps/web          Next.js 15 (App Router) — スタッフ用Web/PWA + お客様向けページ + API/Webhook
packages/core     ドメインロジック（予約エンジン・会計計算・LTV・本人照合・RBAC・暗号化・連携アダプタ）
packages/db       Prisma スキーマ（PostgreSQL）＋マイグレーション
docs/             仕様・アーキテクチャ・開発規約・デプロイ手順
```

## はじめかた（ローカル）

```bash
cp .env.example .env          # PII_ENCRYPTION_KEY / PII_HASH_KEY / CRON_SECRET を設定
docker compose up -d postgres # もしくはローカルの PostgreSQL 16
npm install
npm run db:push && npm run db:seed
npm run dev                   # http://localhost:3000
```

デモログイン: `owner@demo.salon` / `demo1234`（`manager@` `stylist1@` `reception@` なども同じパスワード）
公開ページ例: `/book/aoyama`（ネット予約）、`/s/aoyama`（店舗プロフィール）、`/store/aoyama`（ストア）

## テスト

```bash
npm test          # ユニット + DB統合テスト（PostgreSQL の salonos_test を使用）
npm run test:e2e  # Playwright E2E（受け入れジャーニー）
```
