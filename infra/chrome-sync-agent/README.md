# Salon OS 自動枠止め（Chrome 拡張）

Salon OS の予約に合わせて、**minimo の「すぐ予約」枠とサロンボードの予定を10分ごとに止め・再開**する Chrome 拡張です。
スタッフが媒体で手作業で枠を止めなくても、他の経路で入った予約とダブルブッキングしなくなります。

- 店舗の Mac の Chrome で動きます。minimo へのログインは**その Chrome のログイン**を使います（パスワードは保存しません）。
- 止めた枠は「予約リクエストのみ」になります（お客様は申請だけでき、サロンが承認するまで予約になりません）。
- 予約が取消・変更されたら、拡張が止めた枠だけを元に戻します（他の予約がある時間は戻しません）。
- 止まったとき（Chrome が閉じている・Mac がスリープ・minimo のログイン切れ）は、30分後に店舗のメールアドレスへ「止まっています」と届きます。
- サロンボード: Salon OS・minimo で入った予約の時間に**予定**を入れます（サロンボード上の表示は「予定あり」、メモに「Salon OS の予約で自動登録」）（予定の時間はホットペッパーの予約受付が止まります）。取消・変更されたら、その予定だけを消します。お店で入れた予定（休日・予定あり など）には触りません。SALOGIC から移した予約はサロンボードに入っているので対象外です。
- サロンボードは、拡張機能専用のタブ（ピン留め）を使います。スタッフが開いているサロンボードのタブは動かしません。ただし予定を入れた直後は、別のタブで入力途中の画面で保存がエラーになることがあります（入れ直せば保存できます）。

## 入れ方

1. Salon OS → **外部連携 → 予約媒体 → 自動枠止め（Chrome）→ トークンを発行**。店舗を選んで発行し、表示されたトークンをコピー（表示は一度だけ）。
2. Chrome で `chrome://extensions` を開き、右上の **デベロッパー モード** をオン → **パッケージ化されていない拡張機能を読み込む** → このフォルダ（`chrome-sync-agent`）を選ぶ。
3. ツールバーのパズルのアイコン → **Salon OS 自動枠止め** → 設定画面にトークンを貼り付けて **保存** → **今すぐ実行**。「正常」と出れば接続できています。
4. 同じ Chrome で minimo サロンツール（https://minimodel.jp/salontool/home）とサロンボードにログインしておく。拡張は各媒体のタブを1つずつ（ピン留めで）使います。閉じても次の実行で開き直します。
5. Salon OS に戻り、**minimo の枠止めを自動にする**・**サロンボードの枠止めを自動にする** をオン。次の実行（10分以内）から枠を止めます。

拡張機能を更新したときは、`chrome://extensions` の「Salon OS 自動枠止め」のカードの ↻（再読み込み）を押してください。

## 動かし続けるために

- Chrome を開いたままにし、Mac がスリープしないようにする（システム設定 → ディスプレイ／バッテリー）。
- minimo・サロンボードのログインが切れたら、その Chrome でログインし直す（拡張のアイコンに赤い「!」が出ます。30分たっても直らないと店舗にメールが届きます）。サロンボードは10分ごとにトップ画面を読んでログインを保ちます。

## 仕組み

`background.js` が10分ごとに:
1. minimo のスケジュールから施術者の一覧を読む（`GET /api/v1/salontool/schedule`、minimo のタブの中で実行）
2. Salon OS に施術者を渡し、止める・再開する枠を受け取る（`POST /v1/agent/plan`）
3. その日のスケジュールを読み、枠を外して保存する（`POST /api/v1/salontool/schedule`。画面の「変更を保存」と同じ形）。保存後に読み直して確認
4. 結果と minimo のログイン状態を Salon OS に報告（`POST /v1/agent/report`）

枠の計算は `lib/minimo.js`・`lib/salonboard.js`（テスト: `node --test infra/chrome-sync-agent/lib/*.test.mjs`）。

サロンボードは、スケジュール画面の「予定」ボタンと同じ `POST /KLP/schedule/salonSchedule/updateStaffShift/` で予定を入れ、予定変更画面（`/KLP/set/scheduleChange/?date&hour&minute&staffId`）で確かめ、同じ画面の削除（`…/scheduleChange/doDelete`）で消します。
